# SAKIBDESIGNLAB — নতুন পোর্টফোলিও ওয়েবসাইট

## যা যা আছে
- বাংলা / English — দুই ভাষা, শুরুতে **English** দেখাবে
- হিরো সেকশনে বড় ছবি, ফোন/ইমেইল/লোকেশন, WhatsApp বাটন
- "কেন আমাকে হায়ার করবেন" সেকশন + দক্ষতা/টুলস ট্যাগ
- **Google Drive বাটন** — এডমিন প্যানেল থেকে লিংক বসালেই বাটন দেখাবে, খালি রাখলে বাটন লুকানো থাকবে
- লোডিং স্ক্রিন (লোগোসহ)
- এডমিন প্যানেল (Decap CMS) — নাম, ছবি, কাজ, ক্যাটাগরি সব ব্রাউজার থেকেই বদলানো যায়

## আগের সাইট থেকে যা বসানো আছে
আপনার আগের `sakibdesignn.netlify.app` সাইটের দেওয়া তথ্য থেকে এসব বসানো হয়েছে:
- নাম, ট্যাগলাইন, বায়ো (বাংলা+English)
- ফোন, ইমেইল, লোকেশন, WhatsApp নাম্বার ও মেসেজ
- বছরের অভিজ্ঞতা, প্রজেক্ট সংখ্যা, ক্লায়েন্ট সংখ্যা
- একটা পোর্টফোলিও আইটেম ("লোগো / Logo")

## যা আপনাকে এখনো করতে হবে
- **প্রোফাইল ছবি** — আসল ছবিটা (`kh-1-.png`) এই প্রজেক্টে নেই (আমি সরাসরি ফাইল আনতে পারিনি), তাই এখন একটা প্লেসহোল্ডার বসানো আছে। `/admin` → "সাইট তথ্য" → "Profile Photo" থেকে আসল ছবি আপলোড করে দিন।
- **পোর্টফোলিওর কাজের ছবি** — একইভাবে `/admin` → "পোর্টফোলিও কাজ" থেকে "লোগো" আইটেমের আসল ছবিটা আপলোড করে দিন।
- **ক্যাটাগরি ও "কেন হায়ার করবেন"** — এখন ডিফল্ট নমুনা তথ্য বসানো আছে, `/admin` থেকে নিজের মতো করে বদলে নিন।
- **Google Drive লিংক** — `/admin` → "সাইট তথ্য" → "Google Drive Link" এ আপনার Drive ফোল্ডার/ফাইলের শেয়ার লিংক বসিয়ে দিন। খালি রাখলে বাটন দেখাবে না।

## ডেপ্লয় করার পর এই একটা কাজ ভুলবেন না (লিংক প্রিভিউর জন্য)

`index.html` ফাইলে ৩ জায়গায় `YOUR-DOMAIN-HERE` লেখা আছে (উপরের দিকে `<head>` অংশে)। সাইট লাইভ হওয়ার পর, সেই আসল ঠিকানা (যেমন `sakibdesignlab.netlify.app`) দিয়ে এই ৩টা জায়গা বদলে দিন — তাহলে Facebook/WhatsApp এ লিংক শেয়ার করলে সুন্দর প্রিভিউ কার্ড দেখাবে। এই কাজটা GitHub এ গিয়ে `index.html` ফাইলে সরাসরি এডিট (✏️) করে করা যাবে, নতুন ZIP লাগবে না।

## ডেপ্লয় করার ধাপ (আগেরটার মতোই)
1. GitHub-এ একটা নতুন repository বানান
2. এই ফোল্ডারের সব ফাইল আপলোড করুন
3. Netlify তে গিয়ে "Import an existing project" দিয়ে repository ইম্পোর্ট করুন, Deploy করুন
4. Netlify সাইট সেটিংসে Identity চালু করুন, Registration → Invite only, Git Gateway চালু করুন
5. নিজের ইমেইলে Identity Invite পাঠান, লগইন করে `/admin` এ ঢুকুন

## নতুন কাজ/ক্যাটাগরি যোগ করা
আগের সাইটের মতোই — `/admin` এ লগইন করে বাম পাশের মেনু থেকে সংশ্লিষ্ট সেকশনে গিয়ে যোগ করুন। প্রতিটা ফিল্ডে Bangla ও English দুটো ভার্সন আলাদাভাবে লেখার জায়গা আছে।

## মাসিক ফ্রি সীমা নিয়ে সতর্কতা
Netlify-র ফ্রি প্ল্যানে মাসিক একটা বিল্ড সীমা আছে। স্বাভাবিক ব্যবহারে (মাসে কয়েকবার আপডেট) এটা কখনো শেষ হওয়ার কথা না। যদি কখনো "Deploy skipped / operational credits" এই ধরনের বার্তা দেখেন, তাহলে হয় পরের মাস পর্যন্ত অপেক্ষা করুন (সাইট ততক্ষণ লাইভই থাকবে), অথবা GitHub Pages-এ সম্পূর্ণ ফ্রি (সীমাহীন) হোস্ট করার বিকল্প পদ্ধতি জানতে বলুন।
